# Glossary of Terms

A reference guide for TaintFlow architecture terms.

---

### **AST**
Abstract Syntax Tree. Generated by tree-sitter parsers to represent code structure.

### **CFG**
Control Flow Graph. A graph mapping all executable paths through a function or application.

### **IFDS**
Interprocedural Finite Distributive Subset problem. The mathematical framework utilized to trace data flow paths.

### **SSA**
Single Static Assignment. An IR format requiring each variable to be defined exactly once.

### **SARIF**
Static Analysis Results Interchange Format. A JSON schema specification representing SAST results.

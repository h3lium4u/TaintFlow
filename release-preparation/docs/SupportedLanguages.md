# Supported Languages

TaintFlow officially supports security flow tracking for Java and Python codebases.

---

## Java
- **Language Versions**: Java 8 through Java 21.
- **Parsing Mechanism**: High-fidelity parser with support for nested classes, interfaces, generic type definitions, and try-with-resources.

---

## Python
- **Language Versions**: Python 3.8 through Python 3.12.
- **Parsing Features**: Implements full SSA lowering for Python 3.10+ pattern matching (`match-case`), wildcards, OR patterns, list comprehensions, and keyword arguments.

Refer to [SupportedFrameworks.md](SupportedFrameworks.md) to see modeled libraries.

# Security Maintenance Policy

This policy governs the reporting, patching, and disclosure of security vulnerabilities within TaintFlow.

---

## Patching Process

- **Dependency Vulnerabilities**: Monitored weekly via automated GitHub Action audits. Vulnerable dependencies are updated in the next patch release.
- **Engine Security Fixes**: Released as minor or patch upgrades directly.
- **Reporting Vulnerabilities**: See the [Security Policy](../SECURITY.md) for private disclosure instructions.

# Offline Operation Guarantee

TaintFlow guarantees full, unrestricted offline operation.

---

## Commitments

- **No Remote Dependencies**: Once compiled, TaintFlow requires no external servers, API keys, or network connections.
- **Air-Gapped Compliance**: The CLI tool can be deployed directly into secure, network-isolated (air-gapped) environments.
- **Deterministic Scanning**: Scanning and rule execution are performed entirely locally and deterministically on the provided workspace.

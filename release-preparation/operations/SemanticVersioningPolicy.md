# Semantic Versioning Policy

TaintFlow strictly implements Semantic Versioning 2.0.0.

---

## Rules of Versioning

1. **Major Version Bump**: Triggered by breaking changes to CLI arguments, rule-matching logic syntax, or SARIF schema properties.
2. **Minor Version Bump**: Triggered by new features, adding support for new languages, frameworks, or additional configuration capabilities.
3. **Patch Version Bump**: Triggered by backward-compatible bug fixes (false positive reductions, parser crash fixes).

# Telemetry Statement

TaintFlow does **not** collect or transmit telemetry, analytics, or usage statistics.

---

## Technical Details

- **Zero Phone-Home Code**: There are no network requests, tracking pixels, or telemetry reporting hooks compiled into the TaintFlow engine.
- **Offline Guarantee**: You can execute TaintFlow inside air-gapped, offline environments without configuring proxy variables or bypass lists.
- **Opt-Out is Default**: You do not need to pass an `--opt-out` flag or set environment configurations. TaintFlow is telemetry-free by design.

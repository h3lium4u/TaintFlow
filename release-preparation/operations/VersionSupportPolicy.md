# Version Support Policy

TaintFlow maintains support bounds for active releases to minimize maintenance overhead.

---

## Support Matrix

| Release Series | Status | Security Patches | Bug Fixes |
| :--- | :--- | :--- | :--- |
| **v1.0.x** | **Active Support** | Yes (Core / Deps) | Yes |
| **v0.9.x (Beta)** | **Deprecated** | Critical Only | No |
| **v0.8.x and prior**| **End-of-Life** | No | No |

We officially support the current major release series only.

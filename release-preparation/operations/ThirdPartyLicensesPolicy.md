# Third-Party Licenses Policy

All dependencies compiled into TaintFlow must comply with our open-source distribution policy.

---

## Allowed License Categories
- **Permissive**: MIT, Apache 2.0, BSD-2-Clause, BSD-3-Clause.
- **Copyleft (Restricted)**: GPL, LGPL, and AGPL licenses are **prohibited** within core compiled binaries to protect our consumers.

License compliance checks are enforced on every pull request using `cargo deny`. Refer to [LicenseCompliance.md](LicenseCompliance.md) for details.

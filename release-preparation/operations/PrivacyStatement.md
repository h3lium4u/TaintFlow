# Privacy Statement

TaintFlow is designed to protect your privacy and source code integrity.

---

## Commitments

- **No Source Code Ingestion**: TaintFlow is an offline analyzer. Your source code never leaves your local machine or build runner.
- **No Remote Tracking**: We do not use remote analytics cookies or store user metadata.
- **No Third-Party Access**: Since TaintFlow runs entirely locally, third parties have no access to your code, scan configurations, or vulnerability results.

# Support Matrix

This matrix outlines TaintFlow v1.0.0 support tiers for platforms, languages, and frameworks.

---

## Tiers

### Tier 1: Fully Supported
We compile native binaries, run automated CI, and certify 100% recall.
- **Platforms**: Linux (x86_64), Windows (x86_64), macOS (x86_64/ARM).
- **Languages**: Java (8, 11, 17, 21), Python (3.8 - 3.12).
- **Frameworks**: Spring MVC (Java), Flask (Python).

### Tier 2: Community Support
Community-contributed integrations and platforms.
- **Platforms**: BSD, Linux (aarch64).
- **Languages**: Python (3.7).

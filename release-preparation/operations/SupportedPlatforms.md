# Supported Platforms

TaintFlow compiles to native binaries on multiple operating systems and architectures.

---

## Operating Systems

### Linux
- **Architectures**: `x86_64`, `aarch64`.
- **Target Triples**: `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu`.

### Windows
- **Architectures**: `x86_64`.
- **Target Triples**: `x86_64-pc-windows-msvc`.

### macOS
- **Architectures**: `x86_64`, `aarch64`.
- **Target Triples**: `x86_64-apple-darwin`, `aarch64-apple-darwin`.

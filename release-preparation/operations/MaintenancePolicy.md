# Maintenance Policy

TaintFlow maintains active versions by applying backports for security vulnerabilities and scanner crashes.

---

## Maintenance Guidelines

- **Bug Triage**: Bugs are evaluated for impact on precision/recall and overall compiler stability.
- **Hotfixes**: Critical crash bugs trigger a prompt patch release.
- **Scheduled Maintenance**: Standard bug fixes are consolidated into monthly patch releases.

For version boundaries, see [VersionSupportPolicy.md](VersionSupportPolicy.md).

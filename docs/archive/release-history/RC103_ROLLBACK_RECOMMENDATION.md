# RC103 Rollback Recommendation

## 1. Recommendation: B. Partial Rollback

**Recommendation:** Keep the Sink Argument Gating logic, but **ROLLBACK** the Source Seeding Refinement (specifically the `is_private` / `starts_with('_')` filter).

## 2. Justification

### Why rollback the Source Seeding Refinement?
The Source Seeding Refinement (`method.name.starts_with('_')`) caused catastrophic recall damage. It directly wiped out 100% of the Vul4J True Positives by severing the entry-point discovery logic for test-invoked public wrapper methods. Furthermore, it explicitly blocked the Python `_wget_download` CWE-78 vulnerabilities in PaddlePaddle and similar GitPython/OWASP paths. The precision gained by dropping uncalled private methods is vastly overshadowed by the critical security holes it created in the analyzer's coverage.

### Why keep Sink Argument Gating?
The Sink Argument Gating rule for CWE-502 was highly effective at suppressing False Positives generated by static configuration loaders. While it did cause a minor regression of ~5 TPs (where serializers rely on parameter-less initializations), the massive $+28$ True Negative gain in the GitHub holdout was largely driven by this gating mechanism. It is fundamentally sound but requires a minor patch in the future to handle field-sensitive `self` attributes rather than a full rollback.

## 3. Estimated Impact of Partial Rollback

If we revert the Source Seeding Refinement while retaining Sink Argument Gating:

*   **Recall Recovered:** We will instantly recover the **12 Vul4J TPs** (bringing Vul4J recall back to its baseline) and recover the **~20+ GitHub/OWASP TPs** that were blocked by the `_` prefix logic. Combined recall will return to `~85.00%`.
*   **Precision Retained:** We will retain the majority of the False Positive suppressions. The GitHub Precision should stabilize around `~58.00%` (down slightly from 59.18%, but still above the RC101A baseline of 56.60%), keeping the engine beta-ready without sacrificing the core command-injection and path-traversal detection capabilities.

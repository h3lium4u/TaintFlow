# RC190 — Hybrid JavaBean Propagation Implementation Plan

## 1. Architecture Overview

To support generic JavaBean DTO propagation without writing framework-specific rules (for Spring, Jackson, Gson, Micronaut, etc.), we will modify the interprocedural solver's transfer functions in the `taint` crate.

The engine will implement a hybrid strategy to determine if a call represents a JavaBean getter/setter:
- **Priority 1 (Semantic Body Inspection)**: If the call maps to a method with an IR body available, we check if the method semantically returns a field (getter) or assigns to a field (setter).
- **Priority 2 (Naming & Signature Fallback)**: If the method is unparsed (precompiled library or Lombok-generated bytecode), we fallback to signature patterns:
  - **Getter**: Starts with `get*` or `is*` with 0 arguments and a non-void return type, excluding a structural blocklist.
  - **Setter**: Starts with `set*` or `with*` with 1 argument.

## 3. Algorithm Description

Within `interproc.rs`, in the transfer function for `InstructionKind::Call`:

### A. Getter Detection Function
```rust
fn is_javabean_getter(
    program: &ir::Program,
    gst: &symbols::global::GlobalSymbolTable,
    callee_method_id: Option<ir::MethodId>,
    method_name: &str,
    args_len: usize,
) -> bool {
    if args_len != 0 {
        return false;
    }

    // 1. Semantic Body Inspection (Priority 1)
    if let Some(m_id) = callee_method_id {
        if let Some(method) = program.methods.get(&m_id) {
            // Check if the method body consists solely of returning a field of `this`
            if method.body.len() == 1 {
                if let Some(inst) = program.instructions.get(&method.body[0]) {
                    if let ir::InstructionKind::Return { val: Some(expr) } = &inst.kind {
                        if expr.contains("this.") {
                            return true;
                        }
                    }
                }
            }
        }
    }

    // 2. Naming Fallback (Priority 2)
    let m_lower = method_name.to_lowercase();
    let blocklist = [
        "size", "length", "hashcode", "clone", "iterator", "stream", 
        "values", "keyset", "entryset", "isempty", "get", "getinstance",
        "getclass", "getclassloader", "getconnection"
    ];
    if blocklist.contains(&m_lower.as_str()) {
        return false;
    }
    m_lower.starts_with("get") || m_lower.starts_with("is")
}
```

### B. Setter Detection Function
```rust
fn is_javabean_setter(
    program: &ir::Program,
    callee_method_id: Option<ir::MethodId>,
    method_name: &str,
    args_len: usize,
) -> bool {
    if args_len != 1 {
        return false;
    }

    // 1. Semantic Body Inspection (Priority 1)
    if let Some(m_id) = callee_method_id {
        if let Some(method) = program.methods.get(&m_id) {
            // Check if the method body consists of assigning the parameter to a field of `this`
            if method.body.len() == 1 {
                if let Some(inst) = program.instructions.get(&method.body[0]) {
                    if let ir::InstructionKind::Assign { dest, .. } = &inst.kind {
                        if dest.contains("this.") {
                            return true;
                        }
                    }
                }
            }
        }
    }

    // 2. Naming Fallback (Priority 2)
    let m_lower = method_name.to_lowercase();
    m_lower.starts_with("set") || m_lower.starts_with("with")
}
```

## 4. Safety Rules (FP Audits)

- **`UserDto.getUsername() / setUsername()`**: Correctly matches naming and semantic checks (Taints propagate safely).
- **`Connection.getMetaData()`**: Excluded by blocklist (`getconnection` patterns block connection-level metadata).
- **`List.get()` / `Map.get()`**: Excluded by blocklist (`get`).
- **`size()` / `length()` / `hashCode()` / `equals()`**: Excluded by blocklist (prevents structural checks from propagating taint).
